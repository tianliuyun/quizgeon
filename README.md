# Quizgeon · 题牢

> 肉鸽式刷题地牢 — 用游戏化学习，让刷题像打地牢一样上瘾。

**Quizgeon** 是一个题库驱动的 Roguelike 地牢闯关游戏。玩家通过答题打怪，答错掉血、答对赚金币，在死亡与重来中记住知识。

内置 **大模型面试题库**（3 层 / 33 题），也支持自定义题库。

---

## ✨ 特性

- 🎮 **肉鸽玩法**：随机地牢、死亡重来、错题追着你打（间隔重复学习法）
- 📚 **学习模式**：先看知识点解析再答题，适合新学内容
- 💾 **自动存档**：中途退出自动保存，回来继续玩
- 👾 **Boss 战**：每层末尾两阶段 Boss，选择题 + 开放题，关键词智能判分
- 🏪 **商店系统**：血瓶、跳过符、50/50 排除，策略搭配
- 📖 **知识点图鉴**：追踪掌握情况，标记薄弱点
- ⚡ **零依赖**：纯 HTML + CSS + JS，不需要构建工具
- 🔊 **音效系统**：Web Audio API 生成，零外部资源
- 📱 **移动端适配**：手机浏览器直接玩

## 🎯 游戏玩法

### 基本规则
- 每层地牢 10 个房间：9 个战斗房 + 1 个商店房（第 5 间）+ 1 个 Boss 房（第 10 间）
- 每道题对应一个怪物，答对 = 怪受伤 + 掉金币，答错 = 你掉血
- HP 归零游戏结束，获得灵魂碎片用于永久升级

### 两种模式
| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 标准模式 | 直接答题，答错看解析 | 复习、自测 |
| 学习模式 | 先看知识点解析，再答题 | 学新内容 |

### Boss 战（两阶段）
1. **阶段一**：选择题热身，打掉 Boss 第一条命
2. **阶段二**：开放题，用自己的话完整回答，关键词匹配判分

### 商店道具
| 道具 | 价格 | 效果 |
|------|------|------|
| 🧪 小血瓶 | 20 金币 | 回复 30 HP |
| 🍷 大血瓶 | 40 金币 | 回复 70 HP |
| ⏭️ 跳过符 | 25 金币 | 跳过当前题，不算对错 |
| 🎯 50/50 排除 | 15 金币 | 排除两个错误选项（单选） |

### 永久升级
用灵魂碎片（每局结算获得）兑换：
- ❤️ 生命上限：每级 +10 HP（最高 3 级）
- 💰 起始金币：每级 +10 金币（最高 2 级）
- 🛡️ 错题抗性：每级降低 15% 错题复现率（最高 2 级）

## 🛠️ 自定义题库

### 添加新题库

1. 在 `questions/` 下新建目录（如 `frontend-interview/`）
2. 每层创建一个 YAML 文件，编号从 `01-` 开始：
```yaml
# 01-html-basics.yaml
- id: html-001
  difficulty: easy      # easy / medium / hard
  type: single          # single / multiple / boolean / open
  question: 题目内容
  options:              # 单选/多选题需要
    - A. 选项A
    - B. 选项B
    - C. 选项C
    - D. 选项D
  answer: B             # 单选：字母，多选：[A, C]，判断：true/false
  explanation: |
    答案解析（学习模式 + 答错时显示）
  tags:
    - html
    - basics
  min_keywords: 3       # 开放题：最少答对几个关键词算过
```

3. 在 `index.html` 中替换 `questions.js` 的数据源，或修改构建脚本

### 题目类型

| 类型 | type | 说明 |
|------|------|------|
| 单选题 | `single` | 4 选 1 |
| 多选题 | `multiple` | 多选，选全才算对 |
| 判断题 | `boolean` | 对/错 |
| 开放题 | `open` | 关键词匹配判分，适合 Boss 战 |

### 关键词判分（开放题）
开放题的 `answer` 字段是关键词数组，答对 `min_keywords` 个以上算通过。
匹配方式：不区分大小写，子串匹配。

## 🎯 学习原理

这个游戏不是瞎做的，背后是经过验证的学习科学：

1. **主动回忆效应（Testing Effect）**：答题比阅读记忆深刻 2~3 倍
2. **间隔重复（Spaced Repetition）**：错题加权出现，在快忘的时候复习
3. **可变奖励（Variable Reward）**：随机地牢 + 随机怪物，每次都不一样
4. **渐进难度（Progressive Difficulty）**：一层比一层难，持续在心流区
5. **元认知反馈**：答对答错立即给解析，知道自己哪里错了
