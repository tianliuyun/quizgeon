# 题库格式规范

> 所有题库使用 YAML 格式，人类可读、方便贡献。

## 目录结构

```
questions/
├── llm-interview/              # 题库 ID（一个主题一个目录
│   ├── 01-transformer.yaml    # 第一层：Transformer 基础
│   ├── 02-pretrain-sft.yaml  # 第二层：预训练与微调
│   └── 03-rag-agent.yaml      # 第三层：RAG 与 Agent
└── README.md                  # 本文件
```

## 单题格式

```yaml
- id: unique-id
  difficulty: easy | medium | hard
  type: single | multiple | boolean | fill | open
  question: |
    题目内容（支持 markdown）
  options:
    - A. 选项 A
    - B. 选项 B
    - C. 选项 C
    - D. 选项 D
  answer: C  # single: 单个字母；multiple: [A, C]；boolean: true/false；fill: 答案字符串；open: 答题要点
  explanation: |
    答案解析（为什么对，为什么错）
  tags:
    - transformer
    - attention
  related:  # 关联知识点（图鉴/速查卡）
    - 自注意力公式
    - 多头注意力
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| id | ✅ | 唯一 ID，格式：`<模块>-<编号>`，如 `trans-001` |
| difficulty | ✅ | easy / medium / hard |
| type | ✅ | single（单选）/ multiple（多选）/ boolean（判断）/ fill（填空）/ open（开放） |
| question | ✅ | 题目，支持 markdown |
| options | 选择/判断题 | 选项数组；判断题可以省略 |
| answer | ✅ | 正确答案；open 类型填「答题要点」列表 |
| explanation | ✅ | 答案解析（学习核心，务必写清楚） |
| tags | 建议 | 知识点标签，用于分类和错题统计 |
| related | 建议 | 关联知识点，链接到图鉴 |

## 难度标准

- **easy**：基础概念题，记住就能答（占 40%）
- **medium**：理解应用题，需要懂原理才能答（占 40%）
- **hard**：对比/设计/场景题，需要综合理解（占 20%）

## 示例

见 `llm-interview/01-transformer.yaml`。

## 贡献指南

1. 新增题目 → 在对应层级 YAML 追加
2. 新主题 → 新建目录 + 至少 10 道题
3. id 命名：`<模块缩写>-<三位编号>`
4. 解析务必写清楚「为什么对」和「其他选项为什么错」
5. 题目不能有歧义，选项不能有争议
